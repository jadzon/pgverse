# Przetwarzanie Elementów Graficznych

W folderze `przetwarzenie_elem_graf` znajdują się rozwiązania dotyczące detekcji poszczególnych elementów graficznych, takich jak tabele, wzory, wykresy i obrazki.

## Podfoldery

- **praca_badawcza** – rezultaty poszukiwania i testowania różnych metod detekcji.
- **rezultaty** – wyniki poszczególnych rozwiązań detekcji.

## Cel
Celem jest skuteczna identyfikacja i klasyfikacja elementów graficznych w dokumentach, co wspiera dalsze etapy przetwarzania OCR.
