
# Instrukcje dotyczące folderów i plików

W folderach znajdują się pliki `README.md`, z którymi należy się zapoznać przed umieszczaniem nowych plików lub wprowadzaniem zmian.

## Zasady
- Każdy folder posiada własne `README.md`, które opisuje jego przeznaczenie oraz zasady organizacji plików.
- Wszystkie nowe pliki Python (`.py`) muszą mieć w nazwie przedrostek `ocr_`.

## Uwagi
Przestrzeganie powyższych zasad pozwoli zachować spójność i czytelność całego projektu.



Folder scalanie_ocr posiada wszystkie pliki potrzebne do przetwarzania książek oraz odpowiednie readme, w której się znajduje instrukcja korzystania.
