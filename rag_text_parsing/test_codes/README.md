# Programy testowe do poprawy RAG-a

Celem jest zbadanie czy podane rozwiązania jest potencjalnie użyteczne i czy będzie opłacało się rozwijać dane zagadnienia.

extraction_of_information.py - używając modelu językowego BERT od facebook-a, program streszcza najważniejsze informacje, aby zoptymalizować przekazywane informacje (na razie użyty został model, który streszcza tylko i wyłącznie tekstu po angielsku)

preprocessing.py - usuwa typowe błędy skanowania, poprawia formatowane itp.
