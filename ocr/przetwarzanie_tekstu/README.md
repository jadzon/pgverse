# Przetwarzanie Tekstu

W folderze `przetwarzanie_tekstu` znajdują się rozwiązania dotyczące przetwarzania tekstu zawartego na wejściowych dokumentach, detekcji rodzaju dokumentu oraz sprawdzania jakości przetworzonego tekstu.

## Zawartość
- Skrypty do ekstrakcji tekstu z dokumentów (np. za pomocą OCR)
- Rozwiązania do automatycznego rozpoznawania rodzaju dokumentu
- Narzędzia do oceny jakości przetworzonego tekstu
