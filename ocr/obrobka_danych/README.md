# Obróbka Danych

W folderze `obrobka_danych` umieszczane są rozwiązania dotyczące wstępnej obróbki danych przed podaniem ich do systemu OCR.

## Cel
Celem obróbki jest przygotowanie danych (np. obrazów, dokumentów) w taki sposób, aby zwiększyć skuteczność działania OCR. Czyli: 

- Skrypty do czyszczenia danych
- Filtry poprawiające jakość obrazów
